  1. Download MiniPadUse the Windows download button above. The file is called MiniPad.exe.

  3. Make it your ownStart with a note. Press F1 for help or F9 to show or hide the preview.

A little help, if you need it.

Do I need to know Markdown?

No. MiniPad works with ordinary plain text. Markdown is optional: simple marks such as a # before a heading add formatting to your preview.

Which Windows versions can I use?

The MiniPad manual lists Windows 8, 8.1, 10, and 11 as fully supported. The app needs .NET Framework 4.0 or later, included in Windows 8 and newer. For older Windows versions and other details, see the system requirements.

I'm using Linux. Where do I start?

The Linux version is minipad.py. It requires Python 3 and Tk. Follow the Linux getting-started instructions in the owner's manual.

Is MiniPad free?

Yes, for personal and commercial use. You may share the unmodified program at no charge. There are restrictions on modifying, distributing, and reusing the source; read the licence for the full terms.

Where can I find the full manual?

Press F1 inside MiniPad for the searchable manual, or read it online. You can also see what's changed.
